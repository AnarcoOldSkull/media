# media

Sistema criado para a escola, fazendo a media dos alunos que possuem nota acima da media escolar, separando os alunos que não atingiram a média em ao menos uma disciplina.
Foi adicionado também ao sistema um conjunto de sistemas para controle de atrasos dos alunos, desta forma fica possível quantificar:
- dias letivos aos quais os alunos se atrazaram;
- tempo de atraso por dia letivo;
- total de tempo de atraso por aluno;
